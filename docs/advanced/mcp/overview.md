# MCP Integration Guide

Connect your AI tools (Claude Desktop, Cursor, etc.) to Intugle using the Model Context Protocol (MCP).

## Quick Start

1. Get your **MCP URL** and **API Key** from your deployed ChatApp settings
2. Configure your MCP client with the credentials
3. Start asking data questions through your AI tool

## What You Can Do

Once connected, your AI assistant can:
- Query your business data in natural language
- Explore metadata and data relationships
- Generate charts, tables, and reports
- Build calculated fields and data products
