# 2.11.0 Release Notes

**Date:** 2026-09-25  
**Environment:** Intugle Staging  
**Release type:** minor

<Tabs>
  <TabItem value="release-notes" label="Release Notes" default>

### API

- Memory (vector memory for chatapp) with DB migrations.
- Context graph and graph-RAG search.
- Agent CRUD, tools, and skills endpoints.
- Graceful shutdown and health endpoints.
- Datadog logger v2 migration.
- Seed skills and workspace initialization.
- Memory import/export.
- effective-user-id refactor.

### UI

- Memory page and deploy-wizard integration.
- Deploy-wizard semantic diff and changes review.
- DloAgentChat and agent builder.
- Context graph search and node vectorization UI.
- Skills management and sync UI.

### Agent v2

- Context graph agent (phase 1).
- mem0 memory agent integration.
- Metadata agent with dynamic tools.
- FastAPI protocol server mounting.
- Logger v2 / Datadog migration.
- Graceful shutdown and health endpoints.

### Jobhandler Async

- Node vectorization pipeline.
- Graceful shutdown with 1-hour drain.
- Health and runtime probes.
- Datadog logger v2 migration.

### AI Services

- No changes in this release.

### Scheduler

- Memory agent Prefect flow.
- Memory cutoff date.

### Platform Fixes

- Multiple DB migrations for memory, app config, and context graph tables.
- GET_TABLES tool renamed to GET_ASSETS in Text2SQLAgentTools.
