# 2.9.0 Release Notes

**Date:** 2026-09-04  
**Environment:** Intugle Prod  
**Release type:** minor

<Tabs>
  <TabItem value="release-notes" label="Release Notes" default>

### API

- Vector collection cleanup on alias names.
- Subscriptions hard-delete support.
- User creation fixed when user does not exist.
- ADLS SAS backward compatibility for uploads.
- User ID column in observability falls back to internal user ID when external user ID is missing for A2A/MCP.

### UI

- Render Complete tool toggle added for response agent.
- Data analysis agent selected by default when deploying chatapps.
- Evaluation Metrics job completion auto-refreshes observability table.
- Connections page blocks upstream trigger when tables have zero columns or rows.
- Recent runs indicators in Jobs page now reflect failures correctly.
- Download Data issue fixed.

### Agent v2

- Configurable Render Complete tool for response agent.
- Agent runtime uses query_id directly.
- Context graph generation bug resolved.
- Data View in Execute Query step stores results at the correct path.

### Jobhandler Async

- No changes in this release.

### AI Services

- No changes in this release.

### Scheduler

- No changes in this release.

### Platform Fixes

- No changes in this release.
