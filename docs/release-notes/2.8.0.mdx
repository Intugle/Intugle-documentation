# 2.8.0 Release Notes

**Date:** 2026-08-28  
**Environment:** Intugle Prod  
**Release type:** minor

<Tabs>
  <TabItem value="release-notes" label="Release Notes" default>

### API

- New EMR connector added.
- MSSQL and EMR data-product creation validated.
- Connection pool fix for agents reconnecting to Postgres.
- Column IDs generated as UUIDs with backward compatibility.
- Multiple table selection race condition fixed with distributed Redis lock.
- Incremental pipeline no longer overwrites use-case summary.
- Snapshot cleanup during new chatapp deployment.
- Workspace import/export now supports moving deployed apps.
- Deployed apps version control.
- Import/export fixed for Databricks and EMR.
- Import/export supports copying vector collections across environments.
- Workspace agent preferences stabilized with reconciliation and distributed locking.
- Metadata updates improved with optimistic UI and backend locking.
- Cached questions search corrected.
- Cached questions now store messages in memory for follow-up questions.
- MCP header string payload issue corrected.

### UI

- Data Product GenUI with Plan, SQL, and Results tabs.
- Attribute selection and join builder with aggregation and calculated fields.
- Human-in-the-loop review system with clarification questions and resolved history.
- Publish workflow with in-chat action and checkpointer memory injection.
- Data product content persistence with save/edit API and deployment progress tracking.
- Deploy wizard updated: chains and user guidance consolidated into Agent Scope, and Enable Data Products toggle added.
- Deployed app mobile sidebar UI issue fixed.
- Sync prompt UI improved with detailed status.
- Memory tab version-control fixes.
- Fix Me reset button added.
- Dialog boxes block close on outside click and resized for calculated field and Run All.
- UI revamp for few-shots, concepts, and cached questions with tags and usage metrics.
- Unstructured document processing: processing pipeline, chat session, and document metadata UI.
- Intugle Flow integration with customized UI and runtime environment support.

### Agent v2

- Data Product Agent supports creation and publish flows with new skills (data-product-creation, data-product-publish, calculated-field).
- New synonym/variation retrieval for concepts and few-shots.
- Vector collection creation updated for synonyms and variations.
- Semantic search and shortlisted-row retrieval optimized.
- Guidance-first SQL generation nudge.
- Response agent nudged to use generative UI tools.
- Configurable tool-call limit middleware.
- Compaction bug fixed so conversational context is preserved.
- Partial stages stored on query abort, disconnect, or timeout.
- Abort, timeout, and disconnect messages are app-level configurable.
- Blank or failed SQL attempts surfaced to the response agent.
- Tracking of external user/session IDs and retrieved few-shot/concept IDs.
- Cached semantic layer info read in deployed apps.
- Unstructured Document Analysis agent enabled as sub-agent and tool.
- Unstructured document processing: parsing, chunking, indexing, page summary, document summary, and tags.

### Jobhandler Async

- Usage metrics tracking job for columns, few-shots, and concepts.
- Databricks data-product jobs show a loading indicator in recent runs.

### AI Services

- No changes in this release.

### Scheduler

- No changes in this release.

### Platform Fixes

- Observability table includes session ID, user ID, internal session ID, and internal user ID.
- Vector collections copied across environments for workbench and deployed apps.
