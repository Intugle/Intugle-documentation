# Editing Workspace Compute Connection Details

This guide explains how to edit the compute connection details for a workspace.

## Steps to Edit Workspace Connection

To edit the compute connection details for an existing workspace:

1. Navigate to the **Workspaces** list.
   ![List Workspaces](./edit-workspace-compute-connection-details/1_ws_list.png)
2. Click **Edit**. In the dialog, you can update the workspace name. Select **Edit Connection Details** to expand the compute connection settings.
   ![Edit Workspace dialog](./edit-workspace-compute-connection-details/2_edit_dialo.png)
3. Update the necessary compute connection details and save your changes.
   ![Edit Connection Details form](./edit-workspace-compute-connection-details/3_edit_dailog.png)
