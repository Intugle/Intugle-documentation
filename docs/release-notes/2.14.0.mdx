# 2.14.0 Release Notes

**Date:** 2026-10-06  
**Environment:** Intugle Staging  
**Release type:** minor

<Tabs>
  <TabItem value="release-notes" label="Release Notes" default>

### API

- oauthlib pinned to >= 4.0.0.
- Seed-skill metadata and workspace initialization.
- Memory import/export endpoints.
- effective-user-id refactor.
- Jobhandler client bumps.

### UI

- Skills history panel, markdown editor, and sync dialog.
- Workspace import/export of memory.
- effective-user-id refactor.
- User config and pagination improvements.
- Skills management UI with history, markdown editor, and sync.

### Agent v2

- Security dependency fixes (mako, multidict, oauthlib, urllib3, pyjwt, gitpython).
- mem0 memory enhancements (caching, TypeSafeClassifier, PII detection).
- Per-subscription skill toggles.
- DDL and universal instruction injection.

### Jobhandler Async

- nltk CVE-2026-81726 fix.
- Skill Sync feature.
- jobhandler-client 0.2.19 bump.

### AI Services

- No changes in this release.

### Scheduler

- No changes in this release.

### Platform Fixes

- Memory import/export in workspace import/export.
- Security dependency updates.
