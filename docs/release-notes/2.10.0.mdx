# 2.10.0 Release Notes

**Date:** 2026-09-15  
**Environment:** Intugle Staging  
**Release type:** minor

<Tabs>
  <TabItem value="release-notes" label="Release Notes" default>

### API

- ADLS SAS upload backward compatibility.
- User creation fix.

### UI

- Removed PaddleOCR support from OCR configuration.
- OCR configuration management.
- Prompt flow unsaved-change detection improved.
- Post-import workspace vector collection fixed.

### Agent v2

- OCR / LiteParse integration with Google DocumentAI.
- Data-product attribute planning improvements.
- Configurable tool-name change.
- GenUI table metadata preservation.

### Jobhandler Async

- MCP view executor transpile-dialect fix.
- Log syntax fix.

### AI Services

- Multi-provider OCR service refactor (Azure DI, AWS Textract, PaddleOCR, Google DocumentAI).
- Vault-based OCR credentials.
- appcore upgraded to 0.6.2.
- Dimension-measure classifier removed.

### Scheduler

- Scheduler image unpinned in this staging revision.

### Platform Fixes

- PaddleOCR support removed from OCR providers.
- AI Services appcore upgraded to 0.6.2.
